#### ## How to use it  
####   
#### You should run the above commands from the root of your git repo,

To get aider to build and run Solvitaire, you should use the `--test-cmd` flag to specify your build and run commands.

### 1. From the command line
When you launch aider, provide the command needed to compile and run your project:

```bash
aider --test-cmd "make && ./solvitaire"
```

If you want aider to automatically attempt to fix any errors it introduces during an edit session, add the `--auto-test` flag:

```bash
aider --test-cmd "make && ./solvitaire" --auto-test
```

### 2. From inside the chat
You can trigger the build/run command at any time using the `/test` command:

```
/test make && ./solvitaire
```

If you already set the `--test-cmd` when you started aider, you can just run:

```
/test
```

Aider will capture the output of these commands. If they fail (e.g., a compilation error), it will use the error messages to suggest and apply fixes.
